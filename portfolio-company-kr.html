CSF-Net: Context-Semantic Fusion Network for Large Mask Inpainting

WACV 2026 · First author

PROBLEM

대규모 마스크 인페인팅은 시각적 단서가 부족할 때 장면에 없던 물체를 만들어 내기 쉽습니다.

ROLE

문제 정의, 모델 설계, 실험, 논문 작성까지 전 과정을 주도했습니다.

APPROACH

Amodal completion으로 가려진 영역의 구조 후보를 먼저 얻고, transformer 모듈로 주변 맥락과 융합하는 plug-and-play 구조를 설계했습니다.

OUTCOME

다양한 마스크 조건에서 물체 환각을 줄이고 구조적 정확도를 개선했습니다. WACV 2026에 게재되었습니다.

핵심: 더 큰 생성 모델보다, 생성 전에 제공하는 구조적 가이드가 더 효과적인 경우가 있습니다.

Single Image Reflection Removal

Samsung Electronics collaboration · 2024.09–2025.01

PROBLEM

세탁기 내부 카메라의 반사광이 이상 탐지 시스템에서 반복적인 false alarm을 일으켰습니다.

ROLE

공동연구 프로젝트에서 반사 제거 모델 개발을 담당했습니다.

APPROACH

운영 중인 탐지 모델을 다시 학습시키기보다, 입력 품질을 높이는 전처리 문제로 재정의해 cross-attention 기반 모델을 학습·튜닝했습니다.

OUTCOME

반사로 인한 오탐을 줄여 모니터링 시스템의 신뢰도를 개선했습니다.

핵심: 파이프라인 전체를 바꾸기보다 실패 원인에 정확히 맞춘 전처리 모델 하나가 더 낮은 위험으로 문제를 해결할 수 있습니다.

산업 안전 이상 탐지 시스템

Independent project · 2026.07

PROBLEM

낙상·미끄러짐과 PPE·구역 위반처럼 성격이 다른 위험 상황을 실시간으로 감지하고 설명하는 시스템이 필요했습니다.

ROLE

시스템 설계, 모델 선정, 데이터셋 구축과 평가를 단독으로 수행했습니다.

APPROACH

시간적 사건인 낙상은 pose 기반 행동 인식으로, 공간적 상태인 PPE·구역 위반은 object detection으로 분리해 각각에 맞는 파이프라인을 설계했습니다.

OUTCOME

AIHub 공사현장·CCTV 데이터로 end-to-end 파이프라인을 평가하고, 경보 신뢰도를 중심으로 한 이벤트 단위 평가를 설계했습니다.

핵심: 안전 시스템의 지표는 단순 정확도보다 사용자가 신뢰할 수 있는 경보를 만드는가에 있어야 합니다.
